# tsqlsharp

"tsqlsharp extension".

## Features
Will format tsql code using the tsqlsharp cli tool.

## Requirements

Will download the only dependency which is the tsqlsharp formatter cli.

## Extension Settings
currently no settings have been made.


## Known Issues

Poor formatting support as the formatter the cli is based on is still in alpha.
